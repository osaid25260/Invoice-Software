# Invoice-Software
Desktop Invoice Software

An offline invoicing application for diagnostic labs. It runs on Windows 7, 8, 10 and 11. No installation is needed: just double-click the .exe.

Data safety

All data is stored on your own computer, in the Documents\RajputanaLab-Data folder. Nothing is sent to the internet or the cloud.
Invoices are protected by a password using AES-256 encryption. Without the password, the data cannot be opened.
Every save is crash-safe. A daily automatic backup is created, and a damaged file is recovered automatically.
Optional extra backup copy to a USB drive or OneDrive folder.

Main features

Create, edit, copy and print invoices (80mm receipt, direct printing supported)
Automatic lab number management
Pending payments and part-payment tracking
Doctor reports with commission
Analytics and daily closing report
Send an invoice via WhatsApp
Excel (CSV) export, backup import and restore
Built-in data check and repair

Settings and security

Customizable receipt footer, address, phone and visible fields
Light/dark themes, zoom and fullscreen
Privacy mode (amounts are blurred)
Auto-lock, and the login pauses after 5 wrong password attempts

Important notes

Please remember your password. If it is lost, the encrypted data cannot be recovered.
The app is not digitally signed, so Windows may show an "Unknown publisher" warning the first time. Click "More info", then "Run anyway".
Copy the data folder to a USB drive or cloud storage from time to time.
